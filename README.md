### 🌸 csakura

<a href="https://github.com/realstrawhat/csakura"><img src="assets/csakura.webp" width="100%" alt="csakura: a pixel cherry tree growing in a terminal"></a>

A cherry tree that grows in your terminal. A new tree every run, falling petals, wind, 15 palettes. C and ncurses. [![stars](https://img.shields.io/github/stars/realstrawhat/csakura?style=flat&label=stars&color=ec82ab)](https://github.com/realstrawhat/csakura/stargazers)

```sh
brew install realstrawhat/csakura/csakura   # macOS
yay -S csakura                               # Arch
nix run github:realstrawhat/csakura          # Nix
```

[Play with it in your browser →](https://kodialex.com/project-csakura)
